# Security Policy

## Reporting a vulnerability

Report security vulnerabilities through the GitHub repository
**Security > Advisories > New draft security advisory**. Do not open
public issues for security reports.

Include:

- Affected version and configuration.
- Steps to reproduce.
- Impact assessment.
- Suggested mitigation, if any.

## Exposed credentials

If a secret was committed or exposed, rotate and revoke the credential
immediately.

## Maintainer commitment

Maintainers never request secrets from reporters or contributors.
